# antitrustBayes deletion red-team, before edits (2026-10-01)

Baseline: 49 test files, 286 test_that blocks; 33.507 s `testthat::test_local(reporter="silent")` with local antitrust 0.99.41 and coordination 0.0.0.9005; 0 failed/0 errors/13 opt-in skips/17 warnings. The enterprise benchmark-harness test file costs 4.394 s of block runtime; its synthetic-market matrix covers 104 cells.

Proposed deletion 1: two tests that instantiate BayesLogit/BayesSim directly. Plausible lost bug: class inheritance changes or BayesSim becomes invalid. Falsification: `test-simulate-dispatch.R` asserts BayesSpecifiedFit extends BayesFit/StructuralFit, S4 simulate dispatch, and an actual public simulation returns BayesSim; `test-params.R` also checks StructuralFit. The direct instantiation tests add no distinct user behavior. Delete.

Proposed deletion 2: randomized `prepare_stan_data` and `prepare_ces_stan_data` field-length/shape tests. Plausible lost bug: misaligned arrays or changed model version could enter Stan. Falsification: the same file checks numerical quantity/revenue shares, market-year mappings, prior reference, dimensions in one-market CES, plus `test-collapsed-gaussian-api.R` checks model version for Logit and CES; the Stan data contract is exercised across exact-k, market quality, and stacked preparations. Retain numerical and boundary checks. Delete only the two broad, nondeterministic structure snapshots.

Proposed deletion 3: benchmark harness manifest, all-cell smoke, and task-path tests from routine testthat. Plausible lost bug: invalid task matrix or worker path collisions corrupt an expensive study. Initial falsification hypothesis: `doc/market_intercept_enterprise/make_manifest.R`, `run_task.R`, and `aggregate.R` each call `mic_validate_manifest`; each task calls `mic_smoke_task`; separate paths are generated by `mic_task_result_path`, and the benchmark's strict aggregator checks all tasks. This suggested that the 104-cell smoke duplicated runnable validation. The independent second pass below disproved that hypothesis for the manifest and synthetic cells.

Proposed move 4: four benchmark DGP/fixture checks (ordered-k support, stress regime, intercept truth, atomic conduct schedule) out of routine testthat into explicit extended validation. Plausible lost bug: benchmark truth becomes inconsistent, invalidating statistical claims. This is real risk, so retain all four in an executable validation file and document the exact command. They protect validation-fixture semantics, not package users on every commit. Do not delete.

Proposed deletion 5: `nu -> Inf` limit assertion in Student-t test. Plausible lost bug: finite-df conditional scale fails to approach Gaussian. Falsification: the assertion independently recomputes the same expression on both sides and never calls package or Stan code. The bivariate density identity and Gaussian/Student-t posterior prediction tests separately protect actual implementation. Delete pure formula check.

Proposed deletion 6: `mc.cores` nonmutation block. Plausible lost bug: helper mutates global option. Falsification: explicit override block already asserts `getOption("mc.cores")` remains unchanged after helper calls. Delete duplicate block.

No high-value FOC, posterior algebra, cross-package, fit-integrity, exact-k evidence, or public simulation test is proposed for removal.

Second-pass proposed deletion: skipped `posterior prediction does not mutate a CmdStanR fit's lazy draw cache`. Plausible lost bug: `posterior_predict` corrupts a live fit's internal cache. The assertion serializes the private CmdStanR object byte for byte, which is not a public contract; harmless lazy cache updates would fail it. It is permanently skipped without an untracked RDS fixture. The preceding public prediction test checks that the fit object is unchanged and the actual replicated outcomes are correct. Delete this unexecutable private snapshot, while retaining public posterior prediction and opt-in estimated-fit integration.

Independent second red-team correction: the manifest uniqueness and 104-cell synthetic smoke appeared redundant with `run_task.R`, but that 124-task runner is archived and currently fails on missing RStan `stanmodels` under CmdStanR. Therefore those two tests are the only runnable across-cell DGP guards. Restored both in the extended fixture check before final verification. Only worker-path uniqueness remains deleted; the strict aggregator and deterministic task-ID path construction make its separate test low-value.
